# Reachy Mini 英語學習夥伴 — 使用指南

## 一、專案概述

### 這是什麼？

這是 Reachy Mini 機器人的**英語學習互動角色**。專為 4–6 歲的台灣小朋友設計，透過 6 款互動遊戲，讓小朋友在玩耍中自然學英文。

機器人扮演的是「也在學英文的好朋友」，而不是老師。所有說明和鼓勵都用台灣中文，只有目標單字和簡單句型使用英文。

### 設計理念

本專案的遊戲設計基於以下經過研究驗證的教學原則：

| 原則 | 說明 |
|------|------|
| **先聽懂再開口** | 讓小朋友先理解英文，再鼓勵說出來，絕不強迫 |
| **TPR 全身反應教學法** | 將英文單字與身體動作結合，增強記憶 |
| **角色反轉** | 讓小朋友「教」機器人英文，研究證實此方法記憶效果最佳 |
| **實物情境學習** | 用相機辨識房間裡的真實物品來教單字，比閃卡有效 |
| **慶祝每次嘗試** | 答對跳舞慶祝，答錯也溫柔引導，不讓小朋友感到挫折 |
| **短回合制** | 每個遊戲 2–3 分鐘就換，符合幼兒注意力長度 |
| **跨對話記憶** | 機器人會記住上次教的單字，下次自然複習 |

完整研究報告請參考 `docs/research_english_learning_games.md` 和 `docs/final_report_english_learning_games.md`。

### 技術架構：Agent Skills 模式

遊戲採用 **Anthropic Agent Skills** 開放標準，實現漸進式載入：

```
第一層：技能目錄（約 300 tokens，開機時載入）
  系統提示詞包含：「可用遊戲：顏色偵探 — 用相機找顏色...」

第二層：技能啟動（約 500–1500 tokens，按需載入）
  小朋友說「我想找顏色！」→ LLM 呼叫 activate_skill("color-detective")
  → 完整遊戲規則注入對話

第三層：遊戲進行
  LLM 按照遊戲規則，使用現有工具（相機、跳舞、表情等）進行互動
```

這意味著：
- **新增遊戲不需要寫程式** — 只要建立一個 `SKILL.md` 檔案
- **不浪費 context** — 只有正在玩的遊戲規則會佔用 token
- **任何人都能編輯** — 遊戲規則是 Markdown 格式

### 6 款遊戲

| 遊戲 | 中文名稱 | 玩法簡述 | 主要學習內容 |
|------|----------|----------|-------------|
| `color-detective` | 顏色偵探 | 機器人用相機看房間，說出一個顏色讓小朋友去找 | 顏色單字、I Spy |
| `simon-says` | 機器人老大說 | 經典 Simon Says，機器人用頭部動作做視覺提示 | 動作詞、身體部位 |
| `teach-robot` | 教我吧小老師 | 機器人假裝忘記英文，讓小朋友當老師教它 | 任何單字、發音、自信 |
| `emotion-mirror` | 情緒鏡子 | 機器人做表情教情緒單字，互相模仿 | 情緒詞彙、I feel 句型 |
| `photo-hunt` | 拍照大冒險 | 給形容詞任務讓小朋友找東西來拍照 | 形容詞、探索 |
| `story-builder` | 魔法故事書 | 小朋友用英文選角色和場景，一起創作故事書 | 動物、顏色、地點 |

## 二、安裝與啟動

### 前置需求

- Python 3.10 以上
- OpenAI API Key（用於語音對話和視覺辨識）
- （選用）Gemini API Key（用於故事書生成）
- Reachy Mini 機器人或模擬模式

### 安裝步驟

```bash
# 1. 複製專案
git clone <repo-url>
cd reachy_mini_conversation_app_zh-TW

# 2. 建立虛擬環境（推薦用 uv）
uv venv --python 3.12.1
source .venv/bin/activate

# 3. 安裝依賴
uv sync

# 如果需要視覺追蹤功能：
uv sync --extra all_vision
```

### 設定環境變數

複製 `.env.example` 為 `.env`，填入必要的 API Key：

```bash
cp .env.example .env
```

在 `.env` 中設定：

```env
# 必填
OPENAI_API_KEY=sk-your-key-here

# 選填（故事書功能需要）
GEMINI_API_KEY=your-gemini-key

# 選擇英語學習角色
REACHY_MINI_CUSTOM_PROFILE=english_learner
```

### 啟動

```bash
# 使用 Gradio 網頁介面（推薦，開發和模擬都適用）
reachy-mini-conversation-app-zh-tw --gradio

# 無介面模式（連接實體機器人時）
reachy-mini-conversation-app-zh-tw
```

啟動後可在瀏覽器開啟 `http://127.0.0.1:7860` 進入互動介面。

### 切換角色的三種方式

| 方式 | 操作 |
|------|------|
| **環境變數** | 在 `.env` 設定 `REACHY_MINI_CUSTOM_PROFILE=english_learner`，重新啟動 |
| **網頁介面** | 啟動後在 Gradio UI 的「Select personality」下拉選單選擇 `english_learner`，按「Apply personality」 |
| **CLI** | `export REACHY_MINI_CUSTOM_PROFILE=english_learner` 後啟動 |

## 三、如何和機器人互動

### 開始對話

啟動後，機器人會以台灣中文打招呼。如果是第一次見面，它會自我介紹並問小朋友的名字。如果之前見過，它會自然提到上次學的英文單字。

### 開始遊戲

小朋友可以用中文告訴機器人想玩什麼，機器人會自動選擇對應的遊戲：

| 小朋友說 | 機器人啟動的遊戲 |
|----------|-----------------|
| 「我想找顏色！」「我們來玩找東西」 | 顏色偵探 |
| 「我想動一動！」「玩 Simon Says」 | 機器人老大說 |
| 「我來當老師！」「教你英文」 | 教我吧小老師 |
| 「做表情！」「玩情緒遊戲」 | 情緒鏡子 |
| 「我想拍照！」「去探險」 | 拍照大冒險 |
| 「講故事！」「編一個故事」 | 魔法故事書 |

如果小朋友沒有特別想法，機器人會主動推薦一個遊戲。

### 遊戲中的互動

每個遊戲都遵循相同的互動模式：

1. **機器人用中文說明** → 用英文說出目標單字
2. **等小朋友回應**（動作、指東西、或說英文）
3. **回應正確** → 機器人跳舞慶祝 🎉
4. **回應不太對** → 機器人溫柔引導，不會讓小朋友覺得丟臉
5. **每 2–3 輪** → 機器人問要不要換遊戲

### 遊戲範例

#### 顏色偵探

```
機器人：（看房間）"I see something... RED! 紅色的！你找得到嗎？"
小朋友：（拿起紅色蘋果）
機器人：（再看一次）"YES! A red apple! Can you say RED APPLE?"
小朋友："Red apple!"
機器人：（跳舞）"Wonderful! 太棒了！"
```

#### 教我吧小老師

```
機器人：（裝睡）"我好睡喔... 英文都忘光了..."
機器人：（看桌上的杯子）"那個... 是 'chair' 嗎？"
小朋友："不對！是 Cup！"
機器人：（超開心）"CUP! Thank you, teacher! 再說一次好嗎？"
小朋友："Cup!"
機器人：（跳舞）"我永遠記住了！你是最棒的老師！"
```

### 機器人會記住什麼

機器人有**長期記憶**功能，跨對話保存：

- **關於小朋友**：名字、年齡、喜歡的主題
- **學習進度**：學過哪些英文單字、玩過哪些遊戲、目前的程度

下次對話時，機器人會自然地複習上次學的單字，例如：「上次你教我 WINDOW，我還記得喔！」

### 每次對話建議流程

一次對話大約 10–15 分鐘，建議流程：

| 階段 | 時間 | 內容 |
|------|------|------|
| 打招呼 | 1 分鐘 | 機器人問好，提到上次學的單字 |
| 暖身遊戲 | 3 分鐘 | 例如「教我吧小老師」複習舊單字 + 學新字 |
| 主要遊戲 | 3 分鐘 | 例如「顏色偵探」或「機器人老大說」 |
| 收尾遊戲 | 3–5 分鐘 | 例如「魔法故事書」用學到的字編故事 |
| 道別 | 1 分鐘 | 機器人數今天學了幾個字，鼓勵小朋友 |

### 注意事項

- **不要強迫小朋友說英文** — 機器人會自然引導，讓小朋友在準備好時才開口
- **每次 3–5 個新單字就好** — 少量多次比一次塞很多有效
- **答錯沒關係** — 機器人設計成會用驚訝和玩笑的方式回應，不會讓小朋友覺得被批評
- **相機需要能看到小朋友和周圍環境** — 確保機器人的相機有清楚的視野

## 四、新增遊戲

如果想新增一個遊戲，**完全不需要寫程式**：

1. 在 `profiles/english_learner/skills/` 下建立新資料夾
2. 在資料夾中建立 `SKILL.md` 檔案
3. 寫入 YAML frontmatter（名稱和描述）+ 遊戲規則

範例：

```
profiles/english_learner/skills/animal-sounds/SKILL.md
```

```markdown
---
name: animal-sounds
description: 動物聲音遊戲 — 機器人學動物叫聲，小朋友猜是什麼動物。適合喜歡動物的小朋友。
---

# 動物聲音 Animal Sounds

## 遊戲流程
1. 機器人模仿動物叫聲："Meow meow! What animal am I?"
2. 小朋友猜動物名稱
3. 猜對就慶祝，教英文動物名稱
...
```

存檔後重新啟動，新遊戲就會自動出現在系統提示詞中，不需要修改任何其他檔案。
